================================================================================
  CATATAN
================================================================================

1. Kedua board menggunakan STM32F407G-DISC1 (Discovery) dengan STM32F407VGT6
2. Transmitter sudah dikonfigurasi lengkap (ADC, SPI, I2C, CAN, UART, USB)
3. Control/Receiver masih menggunakan konfigurasi default Discovery,
   pin NRF24 dan MOTOR_STARTER hanya didefinisikan di user code (main.h)
4. S0 pada Transmitter dipindahkan dari PC0 ke PB0 (menghindari komponen
   onboard OTG_FS_PowerSwitchOn yang mempengaruhi resistansi pull-down)
5. PC7 pada Transmitter digunakan ganda: I2S3_MCK (onboard) dan NRF_CE
   (user code) - perlu diverifikasi apakah konflik
